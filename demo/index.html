安装运行时，准备一个符合 8×9 契约的宠物包，然后用几行 TypeScript 启动。

  1. 1
    安装运行时 使用 pnpm、npm 或你习惯的包管理器。
  2. 2
    托管宠物包 把 pet.json 与 spritesheet.webp 放在同一目录。
  3. 3
    创建宠物 加载清单并选择内联或页面悬浮模式。
github.com/cixiangtao/sprite-pet ↗ 完整文档 ↗ npm 包 ↗
快速开始 TypeScript 
pnpm add sprite-pet
import { SpritePetWidget, loadSpritePet } from "sprite-pet";

const source = await loadSpritePet("/pets/momo/pet.json");
const pet = new SpritePetWidget({
  source,
  width: 192,
  floating: true,
});

pet.setState("working");
