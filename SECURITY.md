# Security

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in public issues.

Use [GitHub private vulnerability reporting](https://github.com/cixiangtao/sprite-pet/security/advisories/new)
to share the affected version, reproduction steps, impact, and any suggested mitigation privately
with the maintainer.

Security fixes, when needed, are delivered as new npm versions. This project does not promise a
fixed response or resolution timeline.
